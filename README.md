## 🎓 Projet de fin d'études — Système d'inspection visuelle par IA
**Zollner Elektronik Tunisia · Février – Juin 2026**

Conception et déploiement d'un système d'inspection visuelle automatisé pour l'insertion de composants électroniques (Through-Hole Technology) :
- Modèle de détection **YOLOv8n** couplé à un classifieur **Vision Transformer (ViT)** pour la vérification de composants et de polarité
- Application **Streamlit** (upload d'image / webcam USB, affichage temps réel, export CSV/PDF)
- Application des méthodes Lean (**VSM, SMED**) pour réduire les temps de cycle de contrôle visuel
- *Code non public (propriété de l'entreprise) — disponible sur demande sous forme de démonstration/capture*

**Technologies :** Python, PyTorch, YOLOv8, ViT, OpenCV, Streamlit
